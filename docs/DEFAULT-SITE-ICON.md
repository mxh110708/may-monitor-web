# Default site icon

Use the maintainer-supplied plum-blossom photograph as the default site icon. The accepted asset is a direct crop from the original file, followed only by bicubic resizing. No generated image, color, contrast, brightness or saturation adjustment is used.

Crop: x=1020, y=240, width=1440, height=1440 from the 3840x2160 source. Retain the sharp foreground flower and the surrounding blossoms. Source SHA-256: `f72fc1b29232d1b6a1d19e3aa6ef654d0f3d9c9af243f340626de00e4c71d733`.

`public/favicon.ico` contains 16/32/48/64/128 pixel frames; `public/icons/` contains 180, 192 and 512 pixel PNGs for touch and installed web icons. Keep photo colors and the source file unchanged. An administrator's explicitly uploaded favicon retains priority; replacing the default must not silently reset that custom setting. Preserve the existing network-only/private-data cache boundaries.
